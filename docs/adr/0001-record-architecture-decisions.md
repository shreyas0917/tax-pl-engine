# ADR 0001: Record architecture decisions

**Status:** accepted · **Date:** 2026-10-26

## Context
Significant design choices in this project (job queue, SQL layer, FIFO scope, blob storage) need a durable, reviewable rationale.

## Decision
Keep one Markdown file per decision in `docs/adr/`, numbered sequentially, with Context / Decision / Consequences sections.

## Consequences
Every later ADR follows this template. Superseded ADRs are kept and marked as such.
